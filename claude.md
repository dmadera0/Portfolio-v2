# Portfolio-v2 — Project Instructions

## Stack
- Vanilla HTML/CSS/JS — no frameworks, no build step, no npm
- Hosted on AWS S3 (origin) + CloudFront (CDN/HTTPS)
- Target audience: software engineering recruiters

## Key files
| File | Role |
|------|------|
| `src/index.html` | Main portfolio page — all content lives here |
| `src/css/styles.css` | All styles + design tokens (`:root` block at top) |
| `src/js/main.js` | Typing effect, scroll reveal, nav, hamburger, contact form |
| `src/js/admin.js` | Admin panel: auth, form builder, HTML generator |
| `src/css/admin.css` | Admin panel styles |
| `src/admin.html` | Password-protected content editor at `/admin.html` |

## Design system — Forest Ember
| Token | Value | Role |
|-------|-------|------|
| `--clr-bg` | `#101A11` | Deep forest green page background |
| `--clr-surface` | `#172119` | Card / panel backgrounds |
| `--clr-surface-2` | `#1E2D20` | Hover / elevated surfaces |
| `--clr-accent` | `#4ADE80` | Primary emerald green — buttons, tags, highlights |
| `--clr-accent-dim` | `#22C55E` | Deeper green variant |
| `--clr-accent-glow` | `rgba(74,222,128,0.18)` | Glow shadows |
| `--clr-cyan` | `#FBBF24` | Secondary warm amber — typed text, timeline hover |
| `--clr-cyan-dim` | `#F59E0B` | |
| `--clr-text` | `#F0FFF4` | Soft mint-white primary text |
| `--clr-text-muted` | `#94A899` | Muted sage secondary text |
| `--clr-text-faint` | `#4A6552` | Very dim text |

Hardcoded RGBA values in the stylesheet use `rgba(74,222,128,…)` for accent and `rgba(251,191,36,…)` for cyan. Update both the CSS variables and the hardcoded values if retheming.

## Fonts
- Headings: **Outfit** (400–800) — loaded via Google Fonts
- Body: **Space Grotesk** (300–600) — loaded via Google Fonts

## Coding rules
- CSS custom properties for **all** colors and spacing — no raw hex in new rules
- No external CSS frameworks
- All JS must be vanilla — no jQuery, no lodash
- 2-space indentation throughout
- SVG icons inline — no emoji as icons

## Deployment
```bash
./scripts/deploy.sh        # build (rsync src/ → dist/) + S3 sync + CF invalidation
./scripts/deploy.sh --skip-build   # skip rsync, just sync + invalidate
```
CloudFront propagation takes ~30–60 s after invalidation.

## Do NOT touch
- `.env` — holds S3_BUCKET, AWS_REGION, CLOUDFRONT_DISTRIBUTION_ID
- `dist/` — build output, gitignored, regenerated by build.sh
- `aws/setup.sh` — one-time infrastructure creation script

## Admin panel
- Lives at `/admin.html`, password-protected (SHA-256 hash in localStorage)
- Edits content via forms → downloads a complete updated `index.html`
- Workflow: edit in admin → Download index.html → replace `src/index.html` → deploy
